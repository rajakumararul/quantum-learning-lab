    Global phase and relative phase

    Global phase: not observable

    eiγ|ψ⟩ ≃ |ψ⟩

    Multiplying the whole state by eiγ changes nothing physical. Every probability is |eiγα|² = |α|², and the Bloch coordinates depend only on α*β and |α|², |β|², in which the factor cancels. So eiγ|ψ⟩ and |ψ⟩ are the same physical state, even though they are different vectors. We write “≃” for this equivalence and keep “=” for exact equality.

    Relative phase: observable

    α|0⟩ + eiφβ|1⟩

    A phase on one amplitude only is different. It leaves P(0) and P(1) unchanged, but it is the Bloch azimuth φ and it changes interference. For example H(|0⟩ + eiφ|1⟩)/√2 gives P(0) = cos²(φ/2): 100% for φ = 0, 50% for φ = 90°, 0% for φ = 180°.

    Rz separates the two

    Rz(φ) = e−iφ/2 · diag(1, eiφ)

    Rz(φ)(α|0⟩ + β|1⟩) = e−iφ/2 (α|0⟩ + eiφβ|1⟩). The factor e−iφ/2 in front is a global phase and is invisible; the factor eiφ on |1⟩ is a relative phase and turns the Bloch vector by φ about Z.

    Why Rz(φ)|0⟩ does not move the Bloch vector

    Rz(φ)|0⟩ = e−iφ/2|0⟩. The state vector really does change (its amplitude acquires the phase e−iφ/2), but β = 0, so there is no second amplitude for a relative phase to act on: the only change is a global phase. Geometrically, |0⟩ is the north pole, which lies on the Z axis, and a rotation never moves points on its own axis. Compare Rz(φ)|+⟩, where the vector moves around the equator.

    Why a 2π rotation gives −|ψ⟩

    The rotation matrices depend on θ/2: Rn(θ) = cos(θ/2) I − i sin(θ/2) n·σ. At θ = 2π this is cos(π) I − i sin(π) n·σ = −I, so Rn(2π)|ψ⟩ = −|ψ⟩ = eiπ|ψ⟩. That is a global phase π: the probabilities and the Bloch vector are exactly as before, so it is the same physical state, but not the same vector. The state vector itself returns to +|ψ⟩ only after 4π. (Within this single-qubit lab the sign is unobservable; it can become observable when a rotation is applied conditionally, controlled by another qubit.)

    What are you seeing?

    Every pure single-qubit state maps to a point on the Bloch sphere. The north pole is |0⟩, the south pole is |1⟩, and equatorial states are equal-probability superpositions. The vector encodes the relative phase as well as the measurement probabilities.

    Try H → S and observe the rotation from the +X direction to the +Y direction. Try H → T → T for the same effect. You can also change θ and φ directly using the sliders.

    For the parameterized rotations, try Ry(90°) from |0⟩ (the same state as H|0⟩), then Rz(90°), and finally Rx(360°): the Bloch vector returns, while the state vector picks up a factor −1.

    Then try Y from |0⟩: the gate inspector shows Y|0⟩ = i|1⟩. The factor i is a global phase. It appears in the state vector, but the Bloch vector and probabilities are exactly those of |1⟩. Compare with H → Z, where the minus sign is a relative phase that moves the Bloch vector from +X to −X.

      Product states and entangled states

      A two-qubit state is separable (a product state) when it can be written as |a⟩ ⊗ |b⟩: one state for q0 and one for q1. Then each qubit has a definite state of its own, both reduced Bloch vectors lie on their sphere's surface, and C = 0. Example: H on q0 gives (|00⟩ + |10⟩)/√2 = |+⟩ ⊗ |0⟩. q0 is in a superposition, but the state is still separable.

      A state that cannot be written that way is entangled. For |ψ⟩ = α|00⟩ + β|01⟩ + γ|10⟩ + δ|11⟩, the test is αδ − βγ: a product (a₀|0⟩ + a₁|1⟩) ⊗ (b₀|0⟩ + b₁|1⟩) always has αδ = a₀b₀a₁b₁ = βγ. The concurrence C = 2|αδ − βγ| therefore measures entanglement: 0 for every product state, 1 for the Bell states.

      In an entangled state the qubits have no individual states. Each one alone is mixed: its reduced density matrix ρ₀ or ρ₁ is not a pure state, and its Bloch vector lies inside the sphere, with length √(1 − C²). What the qubits do have is correlation: in |Φ+⟩ each qubit alone gives 0 or 1 at random, but the two outcomes always agree. Local gates on one qubit, and SWAP, never change C; a two-qubit gate such as CNOT or CZ can.
